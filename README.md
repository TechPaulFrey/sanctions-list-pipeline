# Sanctions List Pipeline

A daily data platform that ingests the UN Security Council Consolidated List, the US OFAC SDN List, the UK Sanctions List and the Nigeria Sanctions List (NIGSAC), keeps full history, tests data quality on every run, and links the same party across lists.

**This is a portfolio demonstration of data engineering. It is not a certified screening product and must not be used for real screening decisions.**

Work in progress. See [BUILD_LOG.md](BUILD_LOG.md) for the plan and progress.
